## 🚀 A Representative MES Project

I once designed and built a **0-to-1 single-sofa process tracking MES** for a sofa company in Shenzhen.

This project made me focus on a practical question:

> **Production data on the floor is not always complete — how should the system still reflect true production progress as accurately as possible under incomplete data?**

The system does not rely solely on manual registration at the current process. It also combines:

**production flow + downstream logistics milestones + relationships between processes**

to infer the completion status of upstream processes.

As a result, even if a progress entry is missed at some intermediate step, the order progress won't simply be shown as wrong.

I like this kind of software design:

> **Don't force the real world to run perfectly according to software rules — instead, let the software understand the imperfections of the real world.**
