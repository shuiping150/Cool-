## 🚀 一个代表性的 MES 项目

曾为深圳一家沙发企业从 **0 到 1** 设计并开发一套**单套沙发工序跟踪 MES**。

这个项目让我比较关注一个实际问题：

> **生产现场的数据并不一定完整，系统应该如何在不完整的数据下，仍然尽可能正确地反映真实生产进度？**

系统不仅依赖当前工序的人工登记，还结合：

**生产流程 + 后续物流节点 + 工序之间的关系**

推断前序工段的完成情况。

因此，即使某个中间环节遗漏了进度登记，也不会简单地导致整个订单进度显示错误。

我比较喜欢这种类型的软件设计：

> **不是要求现实世界完全按照软件规则运行，而是让软件能够理解现实世界的不完美。**
